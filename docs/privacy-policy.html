Política de privacidad de Famyrex

Última actualización: 10 de septiembre de 2026

Famyrex es una aplicación Android de seguridad y bienestar familiar diseñada para ayudar a las familias a comprender y gestionar el uso digital de sus dispositivos de forma segura, transparente y responsable.

Principio de privacidad: Famyrex prioriza el procesamiento local. Para las funciones de familia conectada utiliza Firebase/Firestore únicamente para el estado necesario entre dispositivos autorizados.

Qué puede procesar Famyrex

  • Uso de aplicaciones y estadísticas de uso cuando la familia concede el acceso correspondiente.
  • Estado de protección, alertas, eventos, tendencias e informes generados localmente.
  • Configuración familiar, controles parentales y estado de vinculación del dispositivo.
  • Ubicación y geozonas cuando se concede el permiso de ubicación y se utiliza esta función.
  • Datos derivados de notificaciones únicamente cuando el usuario activa expresamente el servicio de notificaciones y la función correspondiente.
  • Navegación realizada dentro del navegador web integrado de Famyrex.

Ubicación familiar conectada

Cuando un dispositivo infantil está vinculado y la función está activa, Famyrex puede enviar a Firebase/Firestore la última ubicación conocida del dispositivo infantil: latitud, longitud, precisión aproximada y momento de captura. El adulto autorizado puede consultar ese punto y abrirlo directamente en Google Maps para ver la ubicación o iniciar una ruta.

Famyrex conserva únicamente el último punto sincronizado y no crea un historial remoto de recorridos. El dispositivo infantil puede escribir su propio punto y el adulto autorizado puede leerlo mediante las reglas de seguridad de la familia.

Qué no hace

  • No lee contraseñas.
  • No realiza lectura encubierta de chats o mensajes.
  • No utiliza micrófono ni cámara para vigilancia.
  • No vende datos personales ni utiliza publicidad personalizada.
  • No utiliza la ubicación familiar para publicidad.

Dónde se procesan los datos

El funcionamiento principal de Famyrex es local. Firebase/Firestore se utiliza como infraestructura para determinadas funciones de vinculación y supervisión familiar. Los datos de ubicación conectada se limitan al último punto necesario para prestar esta función.

Seguridad web

El navegador web integrado puede comunicarse con Internet. Famyrex puede utilizar Safe Browsing de WebView cuando está disponible. Las listas locales de dominios se procesan en el dispositivo. Famyrex no intercepta el navegador externo ni los mensajes de otras aplicaciones.

Conservación y eliminación de datos

Los datos funcionales se conservan localmente mientras sean necesarios para las funciones configuradas. El último punto de ubicación sincronizado se sustituye cuando el dispositivo infantil publica una nueva ubicación y deja de estar disponible cuando se elimina el documento remoto correspondiente.

Los datos de infraestructura de Firebase pueden estar sujetos a sus propias políticas y retenciones técnicas.

Para eliminar los datos locales: Ajustes de Android → Aplicaciones → Famyrex → Almacenamiento → Borrar datos (la denominación puede variar según el fabricante), o desinstala Famyrex.

Eliminación de cuenta: si has creado una cuenta de Famyrex, puedes iniciar la eliminación desde esta página de eliminación de cuenta. También puedes utilizar el flujo de eliminación disponible dentro de Ajustes de Famyrex.

Permisos y seguridad

Famyrex solicita permisos solo para funciones que los necesitan y el usuario puede revocarlos desde Android. Los secretos de vinculación se protegen mediante Android Keystore y el acceso a la ubicación sincronizada está restringido mediante reglas de seguridad de Firestore.

Interpretación responsable

Famyrex utiliza estados 🟢 normal, 🟠 atención, 🔴 riesgo y ⚪ datos insuficientes. El estado de datos insuficientes no equivale a que todo esté bien. Las alertas son señales para revisar el contexto y no diagnósticos ni acusaciones.
