Política de privacidad de Famyrex

Última actualización: 6 de septiembre de 2026

Famyrex es una aplicación Android de seguridad y bienestar familiar diseñada para ayudar a las familias a comprender y gestionar el uso digital de sus dispositivos de forma segura, transparente y responsable.

Principio de privacidad: Famyrex prioriza el procesamiento local. No mantiene un backend propio ni un historial familiar remoto.

Qué puede procesar Famyrex

  • Uso de aplicaciones y estadísticas de uso cuando la familia concede el acceso correspondiente.
  • Estado de protección, alertas, eventos, tendencias e informes generados localmente.
  • Configuración familiar, controles parentales y estado de vinculación del dispositivo.
  • Ubicación y geozonas cuando se concede el permiso de ubicación y se utiliza esta función.
  • Datos derivados de notificaciones únicamente cuando el usuario activa expresamente el servicio de notificaciones y la función correspondiente.
  • Navegación realizada dentro del navegador web integrado de Famyrex.

Qué no hace

  • No lee contraseñas.
  • No realiza lectura encubierta de chats o mensajes.
  • No utiliza micrófono ni cámara para vigilancia.
  • No vende datos personales ni utiliza publicidad personalizada.
  • No mantiene una cuenta remota de Famyrex en la versión actual.

Ubicación

Las funciones de ubicación y geozonas requieren permisos de Android. La aplicación puede utilizar las APIs de ubicación del dispositivo y servicios de Google Play relacionados cuando están disponibles. La información se utiliza para las funciones locales de protección y no se envía a un servidor propio de Famyrex.

Seguridad web

El navegador web integrado puede comunicarse con Internet. Famyrex puede utilizar Safe Browsing de WebView cuando está disponible. Las listas locales de dominios se procesan en el dispositivo. Famyrex no intercepta el navegador externo ni los mensajes de otras aplicaciones.

Conservación y eliminación

Los datos funcionales se conservan localmente mientras sean necesarios para las funciones configuradas. El usuario puede borrar los datos locales desde los ajustes de Android o desinstalar la aplicación. La versión actual no crea una cuenta remota de Famyrex.

Seguridad técnica

Los secretos de vinculación se protegen mediante Android Keystore. Famyrex evita almacenar claves familiares sensibles en texto plano cuando utiliza el almacén seguro disponible.

Interpretación responsable

Famyrex utiliza estados 🟢 normal, 🟠 atención, 🔴 riesgo y ⚪ datos insuficientes. El estado de datos insuficientes no equivale a que todo esté bien. Las alertas son señales para revisar el contexto y no diagnósticos ni acusaciones.

Contacto

Para cuestiones de privacidad relacionadas con esta aplicación, utiliza el canal de contacto indicado en la ficha de Google Play del desarrollador.
